## Research & Publications
## [Nile Nexus @ BAREC Shared Task 2026](https://aclanthology.org/2026.arabicnlp-sharedtasks.20.pdf)

**Enhancing Fine-Grained Arabic Readability Assessment through Ordinal-Aware Transformer Ensembling and Decision Calibration**

- **Authors:** Sumaiya Zaman, Miftahul Jannat Rishta
- **Method:** Ensemble of MARBERT, CAMeLBERT MSA, AraELECTRA, and AraBERTv2 using ordinal-aware loss functions and validation-based decision calibration.
- **Achievement:** 3rd place in the Strict Track | Blind Test QWK: **0.848**
- **Links:** [Paper](https://aclanthology.org/2026.arabicnlp-sharedtasks.20.pdf) · [ACL Anthology](https://aclanthology.org/2026.arabicnlp-sharedtasks.20/)· [Code](https://github.com/sumaiyaa110/BAREC-Sentence-level-Readability-Assessment---Strict-Track)


### [Nile Nexus @ ArGuard Shared Tasks 2026](https://aclanthology.org/2026.arabicnlp-sharedtasks.41/)

**Leakage-Controlled MARBERTv2–SVM Ensemble for Arabic Harmful-Prompt Classification**

- **Authors:** Miftahul Jannat Rishta, Sumaiya Zaman
- **Method:** MARBERTv2 and TF-IDF character n-gram SVM combined through a Logistic Regression stacking ensemble, supported by leakage-controlled evaluation and five rounds of error-driven data augmentation.
- **Achievement:** 5th place in Subtask B1 | Blind Test Macro F1: **0.860**
- **Links:** [Paper](https://aclanthology.org/2026.arabicnlp-sharedtasks.41.pdf) · [ACL Anthology](https://aclanthology.org/2026.arabicnlp-sharedtasks.41/) · [Code](https://github.com/Mif-taa/arguard-b1)


### [CUET_SYNTHETICA @ EEUCA 2026](https://aclanthology.org/2026.eeuca-1.14/)
**Gated Cross-Modal Attention with Domain-Adapted Text Encoding for Vaccine-Critical Meme Detection**

- **Authors:** Sumaiya Zaman, Miftahul Jannat Rishta, Shiti Chowdhury
- **Method:** Twitter-RoBERTa + CLIP ViT-L/14 with gated cross-modal attention.
- **Achievement:** 3rd place in the shared task | Macro F1: **0.8357**
- **Links:** [Paper](https://aclanthology.org/2026.eeuca-1.14/) · [DOI](https://doi.org/10.18653/v1/2026.eeuca-1.14) · [Code](https://github.com/Mif-taa/VaxMemeStance)

### [CUET_SYNTHETICA @ DravidianLangTech 2026](https://aclanthology.org/2026.dravidianlangtech-1.29/)
**Multi Architecture Transformer Ensemble for Detecting Abusive Tamil Text Targeting Women**

- **Authors:** Miftahul Jannat Rishta, Sumaiya Zaman, Shiti Chowdhury, Hasan Murad
- **Method:** Heterogeneous ensemble of 12 MuRIL, IndicBERT v2, and XLM-RoBERTa-Large classifiers using soft-voting.
- **Achievement:** 4th place in the shared task | Macro F1: **0.8086**
- **Links:** [Paper](https://aclanthology.org/2026.dravidianlangtech-1.29/) · [DOI](https://doi.org/10.18653/v1/2026.dravidianlangtech-1.29) · [Code](https://github.com/Mif-taa/Abusive-Tamil-Text)

### [CUET_SYNTHETICA @ DravidianLangTech 2026](https://aclanthology.org/2026.dravidianlangtech-1.30/)
**Multilingual Transformer Based Hope Speech Detection for Coarse and Fine-Grained Classification in Tulu**

- **Authors:** Sumaiya Zaman, Miftahul Jannat Rishta, Shiti Chowdhury, Hasan Murad
- **Method:** XLM-RoBERTa, MuRIL, and mBERT with soft-voting for coarse-grained classification; XLM-RoBERTa for fine-grained classification.
- **Achievement:** 1st place in both shared-task subtasks | Macro F1: **0.58** (coarse-grained), **0.42** (fine-grained).
- **Links:** [Paper](https://aclanthology.org/2026.dravidianlangtech-1.30/) · [DOI](https://doi.org/10.18653/v1/2026.dravidianlangtech-1.30) · [Code](https://github.com/sumaiyaa110/Hope-Speech-Detection)
